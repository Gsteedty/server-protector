# Server Protector

A Discord bot that protects a server from raids and spam.

## Setup

1. Create a new Discord bot and invite it to your server.
2. Replace `YOUR_BOT_TOKEN` in `.env.example` with your bot token.
3. Install the required packages by running `npm install discord.js` in your terminal.
4. Enable the Server Members Intent, Presence Intent, and Message Content Intent in the Discord Developer Portal.

## Usage

The bot will automatically detect and prevent raids and spam.
